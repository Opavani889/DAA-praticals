# Matrix Chain Multiplication

## Aim
To implement the Matrix Chain Multiplication problem using Dynamic Programming.

## Description
The program finds the minimum number of scalar multiplications required to multiply a sequence of matrices.

## Method Used
Dynamic Programming

## Time Complexity
O(n³)

## Space Complexity
O(n²)

## Language Used
Python

## Conclusion
The Dynamic Programming approach finds the most efficient order of multiplying the matrices with minimum scalar multiplications.
